말투 예시 자리 (CONTENT_PIPELINE.md 9장). 사람이 쓰거나 검토한 좋은 예시 2~3편을 둔다.
- 파일 이름: NN-<이야기>-<지역>.md, 맨 위 한 줄에 prompt 이름·version·설명·버전 규칙.
- version은 story.md·guide_persona.md와 같아야 한다(다르면 서버가 프롬프트를 읽지 않는다).
- 사실은 근거 사실에 있는 것만 쓴다. 예시는 모델에 그대로 붙으므로 말투 기준점이 된다.
- 현재 01·02는 기존 S01·S08을 새 말투로 다시 쓴 초안이며 사람 검토를 기다린다.
- 예시는 서로 다른 틀(시작 방식·끝맺음 조합)이어야 한다. 같은 틀만 있으면 모델이 그 틀을 그대로 따라 한다.
