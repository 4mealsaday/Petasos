## 3. 통과 지역

아래 표는 `demo_route.py`의 **GPS 페이싱 판정**이다(manifest 순서상 첫 매치).
앱의 이야기 선택은 `ReviewedRegionHierarchy`를 쓰므로 천안 구간에서는 결론이 다르다 — 아래 B 참고.

| 시각 | 지역 | 코드 | 체류 | 이야기 (해결 후) |
| --- | --- | --- | --- | --- |
| T+0:00 ~ 16:03 | **천안시** | 44130 | 16분 | ✅ 천안삼거리 (B 참고) |
| T+16:05 ~ 24:51 | 청주 흥덕구 | 43113 | 9분 | ✅ **땅속에서 나온 흥덕사** (신규) |
| T+24:54 ~ 39:05 | 청주 서원구 | 43112 | 14분 | — 음악 구간으로 설계 |
| T+39:09 ~ 59:26 | 대전 **대덕구** | 30230 | 20분 | ✅ **신탄진IC 주변 음식점** (신규) |
| T+59:28 ~ 73:34 | 대전 **유성구** | 30200 | 14분 | ✅ 박람회가 남긴 과학공원 |

> 청원구(43114)는 2초, 대전 서구(30170)는 2초 스쳐 지나간다. 무시해도 된다.

### A — 이야기 공백 43분 → **해결됨**

처음엔 이야기가 천안·유성구 둘뿐이라 가운데 **43분(전체의 58%)이 비어 있었다.**
기존 팩의 대전 이야기 "철도와 함께 자란 대전"은 **동구(30110)** 에 묶여 있는데
이 경로는 동구를 지나지 않아(대덕구 → 유성구) 쓸 수 없었다.

**해결**: 흥덕구·대덕구 이야기를 새로 만들어 팩에 넣고, 서원구는 음악 구간으로 설계했다.
빈 구간(청원구·대전 서구)은 `demo_route.py`가 `passthrough`로 분류해 자동으로 압축한다.

⚠️ 단, 청주 두 구는 기본 `STORY_GROUPS`에 없어서 **8초 만에 통과**해버린다.
`scenario.json`의 `storyGroups`로 각 지역을 독립 그룹으로 선언해야 45초씩 머문다.

### B — 천안 구간 지역 판정 (2026-11-11 정정)

> 이 자리에 "천안시 폴리곤이 동남구를 가려서 천안삼거리 이야기가 안 나온다"고 적었던 것은 **틀렸다.**
> `demo_route.py`의 지역 판정만 보고 내린 결론이었는데, 그건 **GPS 페이싱 전용**이고 앱 동작과 무관하다.

앱은 `ReviewedRegionHierarchy`로 판정한다:

```kotlin
val leaves = matches.filter { it.regionRevisionId !in children }  // 부모가 아닌 것만
val leaf = leaves.singleOrNull() ?: return null                   // → 동남구
fun scope(regionId) = RegionalStoryScope(regionId, chain, ...)    // chain = [동남구, 천안시]
```

천안역에서 두 폴리곤(44130 천안시 · 44131 동남구)에 동시에 들어가면:

| | 값 |
| --- | --- |
| 통과 지역(passageRegionId) | **44131 동남구** (leaf) |
| 재생 가능 이야기 | **44131 + 44130 둘 다** (부모 체인 포함) |

`reviewed-hierarchy-v1.json`에 동남구·서북구가 천안시의 `non_autonomous_district_of_city`로
명시돼 있어서 성립한다. 팩 빌더(`pipeline/regions.py`)도 같은 결론(44131)을 낸다.

**따라서 천안에서는 호두과자·천안삼거리 두 편이 모두 재생 대상이다.**
45초 구간에 2편이 다 들어가지 않을 수 있으니, 영상 프리셋에서 대표 1편을 고르는 쪽이 안전하다.

## 4. 이 경로로 가능한 것 / 불가능한 것

| 연출 | 가능? | 비고 |
| --- | --- | --- |
| 이야기 (천안·흥덕·대덕·유성) | ✅ | 4개 지역, 공백은 이야기 추가로 메웠다 |
| **창밖 안내 — 한빛탑** | ✅ | 도착 8분 전, 이야기 문장 사이에 끼어듦 |
| 창밖 안내 — 그 외 | ❌ | 이 경로엔 한빛탑 1곳뿐 |
| 음악 삽입 | ✅ | 이야기 사이 자동, 15초 고정 |
| 라이브 대화(질문·답변) | ✅ | 단 **그 세션에서 들은 문단**의 사실만 근거가 된다 |
| 네이버 주변 맛집 **실시간 조회** | ❌ | 키 미구독(401) + 앱이 서버 주입 근거를 거부. **이야기로 대체함** |

## 6. 재현 방법

```sh
# 경로 재조회 (route.json이 있으면 덮어쓰지 않는다 — 고정된 경로가 데모다)
PYTHONPATH=server .local/server-venv/bin/python scripts/fetch-scenario-route.py --scenario cheonan-kaist

# GPX만 다시 만들기 (에뮬레이터 불필요, 구간별 체류 시간 확인용)
.local/server-venv/bin/python scripts/demo_route.py --scenario cheonan-kaist \
  --gpx demo/scenarios/cheonan-kaist/route.gpx
```

2·3장의 타임라인은 `maps.apigw.ntruss.com/map-direction/v1/driving`을
`waypoints=127.3866,36.3765`(한빛탑), `option=traoptimal`, `lang=ko`로 직접 호출해 얻었다.
`.env`의 키는 **Directions만 열려 있다** — Geocoding은 403, 지역검색은 401(미구독).
