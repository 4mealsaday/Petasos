# 2026-11-07 실제 콘텐츠 출처 검토 — TX-05 최소 샘플

이번 검토는 실제로 수집한 관광정보에서 **가거도에 관한 두 가지 사실과 짧은 문단 하나**를 골라, 콘텐츠 설치기에 전달할 출처·권리·사실 검토 자료를 만드는 작업이다. API 조회 성공이나 원문 전체를 검증 완료로 승격한 작업은 아니다.

검토 입력은 `.local/content/incoming/public-data-20261107T060329Z-1abd2a4dac8a.json`이다. 앞선 수집본과 동일한 TourAPI 가거도 및 오디 백제문화단지 입구가 들어 있다. 이 문서는 키, 원문 전문, 정밀 좌표를 포함하지 않는다.

문단은 원문의 문학적 표현이나 전문을 복사하지 않고 다음처럼 짧게 자체 정리했다.

> 가거도는 신안군에 있는 섬이다. 가거도에는 독실산이 있다.

이 두 문장만 `normalizedText` 및 문단 본문에 들어간다. 고도·인구·상위 행정구역 이름·운항 시간·요금·현재 운영 상태 등 추가 주장은 사용하지 않았다. 예상 재생시간 `7000ms`는 설치용 추정값이며 실제 TTS 청취 측정값이 아니다. 준비 음성은 없다(`audioRef=null`).

## 사실 확인 근거

TourAPI의 원본 개요에 섬과 독실산이 나오고, 개요·주소에서 신안군을 확인했다. 관광공사의 [공식 영문 가거도 소개](https://english.visitkorea.or.kr/svc/whereToGo/locIntrdn/rgnContentsView.do?vcontsId=93928)에서도 같은 지리적 사실을 확인했다. 이 영문 페이지는 보조 확인과 좌표 비교에만 사용했으며 페이지 본문이나 이미지를 설치 자료로 복사하지 않았다.

독립적인 정부 출처로 [행정안전부 정책뉴스(2023-01-02)](https://m.korea.kr/news/policyNewsView.do?newsId=148910064)를 확인했다. 이 자료는 가거도를 신안군 흑산면의 섬으로 설명하고 독실산을 가거도 경관에 포함한다. 관광정보의 두 사실과 일치한다. 이 기사에서 소개한 특정 연도의 사업 계획이나 당시 인구는 문단에 포함하지 않았다.

두 fact 모두 `kind=verified_fact`이며 두 source를 연결한다. 입력의 `reviewStatus=verified`와 `verifiedAt`은 **위 두 문장에 한정한 검토**를 나타낸다. 원본 600자 개요 전체가 검증되었다는 뜻은 아니다.

## 텍스트 사용 조건

[국문 관광정보 공식 카탈로그](https://www.data.go.kr/data/15101578/openapi.do)는 이용허락범위를 제한 없음으로 표시하고, 활용 가능한 관광정보를 선별 제공한다고 설명한다. 해당 카탈로그를 다시 읽어 조건을 확인했고 원문 페이지의 수집시각·SHA-256을 검토 JSON에 기록했다. 이번 허용 범위는 원본 개요·주소의 짧은 사실 재구성이다. 응답의 `cpyrhtDivCd=Type1`을 텍스트 전체의 권리 근거로 자동 사용하지 않았다.

행정안전부의 [정책브리핑 기사](https://m.korea.kr/news/policyNewsView.do?newsId=148910064)는 기사 하단에서 텍스트의 공공누리 제1유형 이용 조건을 명시하고, 사진 등 미디어는 별도 권리 확인 대상으로 구분한다. [공공데이터포털 이용 정책](https://www.data.go.kr/ugs/selectPortalPolicyView.do)은 제1유형에서 출처 표시와 함께 상업·비상업 이용 및 변경을 허용한다고 설명한다. 이에 따라 이번 두 문장의 자체 정리와 해당 문장으로 만든 문단에만 생성 추론 근거·표시·배포를 허용하고 출처를 남겼다.

사용 조건의 `reviewBasis`에는 허가 범위를 명시했다. 원문 전문, 기사·관광공사의 다른 페이지, 사진·음성·동영상, 외부 모델 학습용 코퍼스에 대한 승인으로 확대하지 않는다. 출처별 `attribution`에는 제공기관, 자료 식별 정보, 날짜, URL과 사실을 재구성했다는 설명을 포함한다.

[오디 공식 카탈로그](https://www.data.go.kr/data/15101971/openapi.do)도 이용허락범위를 제한 없음으로 표시하며 대본·음성·사진을 안내한다. 그러나 이번 검토에서는 백제문화단지 대본의 개별 사실과 표현, 음성·이미지의 자산별 사용 범위를 검토하지 않았다. 기존 오디 후보의 생성·표시·배포 허용값은 모두 false로 남겼다.

## 좌표를 보류한 이유

[저장한 현행 TourAPI 명세](../reference/public-data/tourapi.openapi.json)의 `areaBasedSyncList2` 응답 설명은 `mapx`를 WGS84 경도, `mapy`를 WGS84 위도로 표시한다. 후보 좌표 값은 유한하고 전 지구 위·경도 범위에도 들어간다. 다만 이런 형식 확인만으로 해당 장소의 정확한 대표 지점이라고 확정할 수는 없다.

추가로 [관광공사 공식 영문 페이지](https://english.visitkorea.or.kr/svc/whereToGo/locIntrdn/rgnContentsView.do?vcontsId=93928)의 `TouristDestination` JSON-LD 안 `GeoCoordinates`를 읽어 비교했다. 후보와 공식 페이지 좌표 사이의 Haversine 거리는 **1km 이상, 10km 미만**이었다. 두 값 모두 전 지구 범위 안이며 0 값이나 단순 위·경도 뒤바뀜은 아니었다. 같은 섬의 서로 다른 대표 지점인지는 확인하지 못했다.

따라서 좌표를 임의 교체하거나 평균 내지 않았다. `coordinateVerified=false`를 기록하고 설치 장소의 `latitude`, `longitude`, `coordinateSystem`, 좌표 출처 연결, 좌표 검토 근거 필드는 모두 null로 전달한다. 원본 후보는 그대로 남겨 후속 검토에 사용할 수 있다. 지역 자동 적립, landmark 정책, 경로상 자동 재생 적격성도 승인하지 않았다.

장소에는 이름 `가거도`와 확인한 TourAPI 외부 ID `127480`만 연결한다. 이 설치 입력은 실제 위치 기반 자동 재생을 검증한 자료가 아니다.

## 검토 파일과 설치 경계

기계 판독 입력은 프로젝트의 `.local/content/review/source-review.json`에 저장했다. 디렉터리 권한은 `0700`, 파일 권한은 `0600`이다.

- 형식: `formatVersion=1`, `kind=petasos-content-source-review`
- 파일 SHA-256: `d4131508bb5b5f02cb16ebce020dde3e1b477ba08e806ce4459890744a79e954`
- `sources`, `facts`, `places`, `stories`, `versions`는 검토한 최소 설치 입력이다.
- `reviewMetadata`에는 원본 ID·revision, 후보 파일, 짧은 검토 텍스트, 권리 근거, 좌표 불일치와 보류 항목을 기록한다. 정밀 좌표나 API 인증키는 복제하지 않는다.
- 최종 source/fact/story revision ID와 content hash는 bundle builder가 계산한다. 검토 기록의 hash와 최종 bundle의 hash는 목적이 다르다.

이번 조사에서는 인증된 API 추가 호출을 하지 않았다. 기존 실제 수집본과 공식 공개 페이지를 읽었고 공개 페이지 수집 해시를 기록했다. 이 문서의 완료 범위는 **출처 검토 및 설치 입력 작성**이며, TX-05 DB 원자적 설치와 앱 실행 결과는 별도 개발·검증 기록을 따른다.
