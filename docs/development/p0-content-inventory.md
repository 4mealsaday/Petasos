# P0 대표 경로 콘텐츠 준비 목록

갱신일: 2026-11-09(KST). [제품 명세](../Petasos_제품명세.md)의 **서울역 주변→경부고속도로 축→대전 엑스포과학공원 주변, 5개 묶음·10개 소재**를 유지한다. S01~S10은 [조사·결정 기록](../Petasos_조사_결정기록.md)의 원래 주제다.

현재 **10개 모두 자체 사실문장·수동 대본 seed·명시적 지역 binding을 검토하여 content bundle v2로 컴파일한 상태**다. 제품 DB 설치와 실제 경로·TTS·최종 시연은 이후 검증 대상이다. 채택 범위·권리 근거·private 파일·해시는 [P0 콘텐츠 검토 근거](p0-content-review-evidence.md)에 기록했다.

## 확보한 원자료

기존 공공데이터 키로 TourAPI/Odii **23회 단일 GET**을 실행했다. 모두 HTTP 200 / 제공기관 코드 `0000`, schema 차이 0이었다. 빈 검색 결과도 보존했다. 첫 네트워크 실패 1회와 환경 allowlist 수정 중 로컬 검사 실패 6회는 성공 조회 수에 포함하지 않는다. 모델 호출·미디어 다운로드는 하지 않았다.

원문·정밀 장소 좌표는 `.local/content/api/p0-*-20261109.json`의 private 후보 자료에 있다. 원본의 `review_status=pending`과 허용값 false는 바꾸지 않았다. 직접 확인한 사실만 새 `p0-reviewed-20261109-v1.json`에 선별했다.

추가로 문체부의 문화역 명명 자료, 국사편찬위 실록·공개 카탈로그, 용인시 연혁·당시 의회 기록, 농촌진흥청 천안 호두과자 자료, 국토교통부 대전 철도 브리핑을 읽었다. 개별 출처 URL과 이용 범위는 [검토 근거 문서](p0-content-review-evidence.md)에 있다.

## 이번에 포함하지 않은 내용

- 이미지·성우 음성·원문 전체 대본·향토문화대전 본문·제한적인 기사 표현.
- 호두과자 최초 연도·발명자, 호두 전래 설화, 시장 순위, 엑스포 참가·방문 수.
- 시점별로 다른 공사 상태·운영시간·분수 운영.
- 관광지 좌표를 이용한 도로 경로·현재 위치 추정, 장소 레코드·자동 랜드마크 정책.
- parent 콘텐츠 binding으로 leaf 방문 카드·현재 지역 판정·지역 정책을 자동 승인하는 처리.

## 이어서 연결할 작업

1. v2 bundle을 초기 콘텐츠 catalog/설치 경로에 고정하고 disposable Room에서 설치·재설치·소속 증거 철회·중복 이력을 검증한다.
2. 실제 leaf 지역 판정과 parent 이야기 조회의 관계를 검증한다. 콘텐츠 공급과 방문 정책 검토를 구분한다.
3. TTS 발음·실제 길이·음악 후 전환을 확인하고 같은 stable ID의 새 version으로 대본을 다듬는다.
4. 실제 도로 polyline·duration, 경계 왕복·오차·단절 시험을 바탕으로 지역 정책과 대표 경로 시연을 연결한다.

가거도의 기존 NULL 지역 remap이나 schema 확장은 신규 10소재 공급의 선행조건이 아니다. 기존 가거도 ID·청취 이력을 유지한다. 추후 좌표·이름 대상 연결에도 이야기를 복제해 이력을 우회하지 않는다.
