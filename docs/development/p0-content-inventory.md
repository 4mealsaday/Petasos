# P0 대표 경로 콘텐츠 준비 목록

확인일: 2026-11-09(KST). 범위는 [제품 명세](../Petasos_제품명세.md)의 **서울역 주변→경부고속도로 축→대전 엑스포과학공원 주변, 5개 묶음·10개 소재**다. [조사·결정 기록](../Petasos_조사_결정기록.md)의 S01~S10을 유지한다. 이 문서는 실제 출처 후보와 다음 검토 입력을 정리한 목록이며, 배포 가능한 대본 10개를 설치했다는 기록이 아니다.

신규 10소재는 [기존 content bundle v2](regional-content-bundle-v2.md)의 최초 설치로 각 stable story ID에 검토한 지역을 연결할 수 있다. 가거도의 기존 NULL 지역을 바꾸거나 schema를 확장하는 작업은 이 목표의 선행조건이 아니다. 원래 가거도 story/fact ID와 청취 이력은 유지한다.

## 이번에 실제 확보한 자료

기존 공공데이터 키를 재사용하여 TourAPI/Odii **23회 단일 GET**을 실행했다. 각 응답은 HTTP 200 / 제공기관 코드 `0000`, JSON이며 계약상 schema 차이는 0이었다. 빈 결과도 그대로 저장했다. 자동 페이지 순회·미디어 다운로드·모델 호출은 하지 않았다. 처음의 네트워크 실패 1회와 환경 파일 allowlist 수정 중 로컬 사전 검사 실패 6회는 성공 조회 수에 포함하지 않는다.

검토 파일은 `.local/content/api/p0-*-20261109.json`이다. 모두 `review_status=pending`, 생성·표시·배포 허용값 false를 유지한다. API 원문·정밀 장소 좌표는 이 private 검토 파일에 보존하며, 실제 사용자 이동 자료는 포함하지 않는다. 후속 작업용 요약은 `.local/content/review/p0-content-inventory-draft-20261109.json`에 있다.

## 권리 검토 기준과 확인된 차이

- [TourAPI 공식 카탈로그](https://www.data.go.kr/catalog/15101578/openapi.json)는 자유롭게 활용 가능한 관광정보를 선별 제공한다고 설명하고 이용허락 범위를 제한 없음으로 표시한다. 사진은 별도로 공공누리 1·3유형을 제공한다고 명시한다. 따라서 `cpyrhtDivCd=Type3`만으로 같은 항목의 짧은 자체 사실 요약까지 일괄 금지하거나, 반대로 모든 사진을 변형 가능으로 승인하지 않는다. 최종 리뷰에는 **채택한 텍스트와 사용 범위**를 적는다.
- [Odii 공식 카탈로그](https://www.data.go.kr/data/15101971/openapi.do)와 기존 고정 계약은 대본·음성 등의 제공을 설명한다. 이번 수집은 텍스트 후보 확보에 한정한다. 연기 대사·창작 표현·성우 음성·사진을 통째로 bundle에 넣는 승인이 아니다.
- [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do)은 출처 표시 아래 변경·영리 이용을 허용한다. 이 일반 조건이 특정 기관의 모든 페이지에 자동 적용되지는 않는다.
- [문화역서울284 이용약관](https://www.seoul284.org/cms/content/view/287)의 제13·17조는 사전 승낙 없는 자료 재배포·변경을 제한한다. 운영기관 페이지는 사실 대조용으로 먼저 쓰고, 직접 배포할 normalizedText는 사용 조건이 확인된 API 또는 별도 공개저작물에서 확보한다. [문체부 전시운영 페이지](https://www.mcst.go.kr/site/s_policy/dept/deptView.jsp?pDataCD=0417000000&pSeq=686&pType=02)의 4유형 조건을 보도자료 전체에 일반화해서도 안 된다.
- [용인시 저작권정책](https://www.yongin.go.kr/home/yonginInfo/yonginInfo_05.jsp)과 [안성시 저작권정책](https://www.anseong.go.kr/portal/contents.do?mId=0801000000)은 개별 공공누리 표시 확인을 요구한다. 이번에 읽은 역사/전시 페이지에 해당 표시가 확인됐다고 주장하지 않는다. 표시를 확인하거나 같은 사실을 담은 사용 가능한 공식 자료를 이어서 확보한다.
- 향토문화대전 본문, 업소 사진, 기사 첨부 이미지에 일반 관광 API의 허락을 전용하지 않는다. 불확실한 출처는 `allowGeneration/allowDisplay/allowDistribution=false`로 남긴다.

## 지역·좌표 입력의 완료 조건

1. 각 API 항목의 주소·place identity를 확인한 뒤 원본 좌표의 WGS84 의미와 별도 공식 지도/주소 자료를 대조한다. 위·경도 범위 검사는 장소 검증을 대신하지 않는다.
2. 검토한 위치를 실제 전국 경계에 대입하고 코드·이름·datasetVersion·regionRevisionId를 기록한다. 관광 API 코드와 NGII 코드가 숫자 연결만으로 항상 같다고 가정하지 않는다. 시·구 중첩의 선택 규칙은 지역 정책 작업의 검토 결과를 사용한다.
3. 지역 연결에는 좌표와 별개로 `verified_fact`인 association fact와 현재 이용 가능한 출처가 필요하다. 예를 들어 “문화역 서울 284는 서울 중구에 있다”와 같은 장소 소속은 원본 주소로 검토할 수 있다. 용인 전체의 역사를 특정 구에 연결할 때는 단순한 박물관 주소로 대체하지 않는다.
4. 지역 텍스트 연결과 방문 정책은 별개다. v2를 설치해도 region policy는 자동으로 verified가 되지 않는다. 시연 경로·경계 왕복·오차·단절 검토가 끝난 정책만 별도 정책 catalog로 설치한다.
5. 경로의 예측 순서에는 검토한 실제 도로 polyline과 duration 근거를 사용한다. 관광지 좌표 사이 직선을 실제 도로 경로로 만들거나, 별도 계산한 시연 경로를 Pleos가 선택한 실제 경로라고 표시하지 않는다.

## 바로 이어서 만들 산출물

1. 이 10개 소재 각각의 자체 사실 문장, source URL/수집시각/원자료 해시/개별 사용 범위를 확정한 source-review 입력. 아직 해소되지 않은 S02~S04·S07·S09의 권리·역사 세부 항목은 검토를 이어간다. 사용자가 재승인할 필요가 있는 기본 기능 결정으로 취급하지 않는다.
2. 각 소재의 독립 stable story/fact key와 최소 1개 필수 문단을 가진 v2 콘텐츠 bundle. 기존 가거도 ID를 재사용하거나 같은 내용에 우회용 새 ID를 발급하지 않는다. 10개의 새 소재는 원래 P0 계획의 독립 이야기다.
3. 시·구 선택과 실제 경로가 확인되면 정확한 regionBindings와 별도 방문 정책 review를 완성한다. 미래 지역 예측과 현재 지역 후보 모두 동일한 검토된 소속 의미를 사용한다.
4. 오프라인 builder 검증→disposable Room 원자적 설치/철회/중복 이력 검증→배포 catalog 연결→기기에서 5묶음·10소재 편성 확인 순서로 진행한다. 원자료의 미래 운영 상태나 합성 재생 시간을 실측으로 기록하지 않는다.

현재 추가 키·새 사용자 결정은 이 목록 작성과 다음 사실 검토를 막지 않는다. 실제 사용자 발화 시험이나 별도 경로 API 신규 등록이 필요한 시점은 해당 연결 작업에서 구분해 안내한다.
