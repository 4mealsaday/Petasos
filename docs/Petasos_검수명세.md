# Petasos — 검수 명세

버전 0.8 · 기준일 2026-11-06 · [제품](./Petasos_제품명세.md) · [동작](./Petasos_동작명세.md) · [데이터·API](./Petasos_데이터_API_계약.md)

## 1. 검증 수준과 실행 기록

문서 링크·참조 SQL·JSON 계약 검사는 앱 실행 검증과 별개다. 아래 앱 시나리오는 모두 미실행이다. 로컬 계약 검사 결과는 spec/validation-report.json에 기록하며 해당 결과만으로 SDK·음성·오디오 성공을 표시하지 않는다.

각 실행에는 caseId, requirementIds, 앱/이미지/SDK/DB/API 버전, fixtureId, 초기 DB 상태, 이벤트 순서, 시계 입력, 예상 상태·DB 변경, 실제 결과, pass/fail/blocked, 오류 코드와 재현 절차를 기록한다. 실기기/에뮬레이터/모의 어댑터를 구분한다. 원음·실제 발화 전문·정밀 경로를 일반 오류 로그에 첨부하지 않는다.

## 2. 공통 fixture

| 이름 | 구성 |
| --- | --- |
| F-STORY | story S, 버전 V1의 필수 문단 P1/P2, 같은 story의 V2 문단 Q1/Q2. 각 문단에 검증된 사실·출처 revision 연결 |
| F-SESSION | Trip T, Session X, cancelEpoch=1, stateRevision=1, playIntent=true, blockers 없음 |
| F-MUSIC | 권리 확인한 트랙 M, 반복 OFF, position=30,000 ms |
| F-TURN | Turn U, version=2, 최종 발화·완료 응답이 암호화 임시 저장됨, frozen=true, summaryState=pending |
| F-LOCATION | 원천 시각/수신 시각/품질이 알려진 점, 경계 왕복·중복·단절·오래된 점을 별도로 준비 |

fixture는 합성 데이터이며 실제 사용자 기록을 포함하지 않는다.

| A11 · PR-08/11 | 저장 공간 부족·DB 변경 | 실패 표시, 이전 기록 유지, 마이그레이션 후 FK/개수/내용 검증 | 과거 기록 자동 삭제, 실패한 카드 성공 표시 |
| A12 · PR-05/10 | 시스템 미디어 정지 | TTS·음악·입력 중단, 두 의도 false, checkpoint | TTS만 계속 말함 |
| A13 · P1 경계 | 음식점·카페 검색 결과 수신 | 별도 화면·출처 경로, LLM 요청/요약/영구 기억에 검색 결과 없음 | 검색 결과의 생성·임베딩 입력 |
| A14 · PR-07 | 동일 경로 재주행, 같은 fact의 다른 표현, 명시적 다시 듣기 | 자동 사실 반복 제외, 다시 듣기는 새 attempt로 허용 | 대본 문구만 바꿔 새 사실로 처리 |
| A15 · PR-10 | 음성 출력 중 CarUxRestrictions 변경 | 제한 화면 즉시 닫기/축소, 허용된 음성은 유지 | UI 제한만으로 무조건 모든 음성 정지 |

A12는 시스템 정지, A15는 주행 화면 제한이다. 과거 A12의 두 조건을 분리했다. A13은 P1 회귀 검수이며 첫 데모 완료의 필수 실행 항목이 아니다.

## 8. 경험·성능 평가와 완료 판정

초기 5–8명이 정차·동승·시뮬레이션에서 음악만 듣기/고정 해설/Petasos를 비교한다. 말없이 들어도 재미있는지, 지역에 관심이 생기는지, 함께 듣기 좋은지, 다시 사용할지, 원치 않는 끼어들기가 있는지를 확인한다. 참여 횟수와 지식 암기를 핵심 성공 지표로 두지 않는다.

버튼→입력 가능, 발화 종료→첫 응답 음성, 실제 문단 길이, TTS/STT 실패율, 시간당 위치 저장량, API 사용량을 기록한다. 측정 횟수와 중앙값·p95를 함께 적고 작은 표본을 일반 성능 보장으로 표현하지 않는다.

P0 완료는 A13을 제외한 P0 앱 시나리오, R/D/N 검수와 SDK 필수 연결이 통과한 상태다. 모의 이벤트 시험과 실제 SDK 전달 시험은 각각 결과를 남긴다. 키·데이터·장치 미준비로 실행하지 못한 항목은 blocked/unrun이며 pass가 아니다.
