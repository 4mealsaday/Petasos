# Petasos — 제품 명세

버전 0.8 · 기준일 2026-11-06 · 상태: 구현 기준, 실행 검증 전

Petasos는 지금 지나가는 지역에 맞는 이야기를 기본으로 제공한다. 사용자는 듣기만 해도 즐길 수 있으며, 원할 때 대화에 참여해 질문하거나 자신의 경험을 보태고 이야기의 전개를 바꿀 수 있다.

## 2. 목적과 이용자

일본·대만 당일 투어에서 가이드의 지역 유래·여행 팁·재미있는 이야기 덕분에 이동을 즐겼던 경험이 출발점이다. Petasos는 국내 자동차 이동에도 함께 들을 이야기를 제공한다.

핵심 이용자는 운전자와 동승자다. 아이·어르신도 이해할 수 있는 쉬운 말과 짧은 설명을 기본으로 한다. 이용자가 말하지 않아도 완결된 경험을 제공한다. 개인 경험은 기획의 동기이며 졸음운전 방지 효과나 시장 수요를 입증한 결과는 아니다.

### 제품: 함께 듣는 지역 이야기, 원할 때 참여하는 대화

기본은 듣기다. 말하기 버튼은 가이드에게 손을 들듯 참여하는 기능이다. 질문 외에도 추억·의견·감상을 받아주고 다음 이야기의 전개에 반영한다.

## 3. 요구사항

| ID | 요구사항 | 완료 판단 |
| --- | --- | --- |
| PR-01 | 현재 지역의 근거 있는 이야기를 우선 제공한다. 단순 지역 변경은 진행 중 이야기를 끊지 않는다. | 준비 콘텐츠 1건을 위치와 연결해 청취 가능 |
| PR-02 | 버튼 1회로 발화 1회에 참여한다. 현재 문단과 마무리·유도 문장 뒤 입력한다. | 입력 준비 표시와 마이크 동작 일치, 응답 뒤 자동 재입력 없음 |
| PR-03 | 질문·개인 경험·재생 요청을 구분한다. 사용자의 경험을 공인 사실이나 개인별 취향으로 확정하지 않는다. | 질문과 경험 시나리오에서 적절한 응답·출처 구분 |
| PR-04 | 자동 이야기 전환은 음악 곡 완료 후 한다. 명시적 말하기·정지·시스템 중단은 즉시 음악을 멈출 수 있다. | 곡 완료·일시정지·건너뛰기 구분 |
| PR-05 | 정지 의도와 중단 이유를 보존한다. 앱 복구가 임의 재생·녹음을 시작하지 않는다. | 중단이 겹친 경우에도 사용자 정지 유지 |
| PR-06 | 선정한 주요 랜드마크만 조건부 삽입한다. 사용자 발화 중 지난 후보는 폐기한다. | 만료 후보가 나중에 부활하지 않음 |
| PR-07 | 실제 청취 이력으로 반복을 줄인다. 같은 사실을 표현만 바꿔 새 이야기로 취급하지 않는다. | 명시적 다시 듣기는 허용, 자동 반복은 제외 |
| PR-08 | 이동 기록·대화 요약·청취·수집 기록을 기기에 기한 없이 보관한다. | 재시작·스키마 변경 후 기록 유지 |
| PR-09 | 지역·이야기 카드를 자동 수집한다. 주행 중 조작 게임과 경쟁형 미션은 제외한다. | 실제 통과·완료 근거가 있는 카드만 한 번 적립 |
| PR-10 | 내비·오디오·주행 화면 제한을 플랫폼 규칙에 맞게 처리한다. | 화면 제한과 음성 중단을 독립적으로 검증 |
| PR-11 | 통신·권한·저장 실패를 명시적으로 처리한다. | 실패한 결과를 성공으로 표시하지 않고 가능한 청취 경로 제공 |
| PR-12 | 생성·재생·저장을 유효한 요청과 데이터 버전에만 반영한다. | 취소·지연·중복·순서 역전 결과가 상태를 훼손하지 않음 |

## 4. 데모 범위

P0는 서울역 주변→경부고속도로 축→대전 엑스포과학공원 주변의 대표 시나리오다. 5개 지역·장소 묶음과 10개 이야기 소재를 준비한다. 정확한 도로 경로·좌표·대본은 아직 검증 전이다.

P0에는 지역·관심사 이야기, 화면 말하기 버튼, 질문·경험 응답, 권리를 확보한 내부 음악, 반복 방지, 정밀 경로·요약 저장, 지역·이야기 카드, 미디어 제어·주행 제한을 포함한다. 한 명의 진행자와 차량/세션 공용 기억을 사용한다.

| 범위 | 항목 |
| --- | --- |
| P1 | 음식점·카페 요청형 검색, 외부 음악 복귀, 물리 말하기 버튼, Gleo 앱 명령, 이야기 북마크·상세 출처 화면, 사용자 선택 다운로드 |
| P2·확장 | 여러 경로, 가족별 설정, 다국어, 칭호·캐릭터·배지, ccNC 테마 |
| 보류 | 여러 AI 진행자, 실시간 뉴스, 자유 연속 대화 |
| 제외 | 주행 조작 게임·경쟁 미션, 운전자 사연 커뮤니티, 일정 비서, 감정·피로 진단, 차량 분위기 제어 |

지역·이야기 카드는 자동 수집한다. 북마크 명령은 P1이므로 P0에서 저장됐다고 응답하지 않는다. 음식점·카페 검색은 첫 데모에 포함하지 않으며 네이버 검색 결과는 생성·요약·개인화 입력에서 제외한다.

## 5. 대표 경험

1. 이동 세션을 시작하면 지역 이야기를 듣는다.
2. 말하기를 누르면 문단이 끝난 뒤 입력 신호가 나온다.
3. 질문 또는 개인 경험을 말하면 답변을 듣는다.
4. LLM이 유효한 복귀 후보 중 이야기상 이어갈 위치를 선택하고, 앱이 실행 가능성을 검사한다.
5. 이야기를 마치면 음악으로 쉰다. 다음 이야기는 현재 곡 종료 후 시작한다.
6. 같은 길에서는 다른 소재를 제공하거나 음악을 유지한다. 도착 후 이동 기록과 수집 결과를 확인한다.

기록 일시정지와 미디어 일시정지는 다르다. 미디어를 멈춰도 이동 세션이 열려 있고 위치 수신이 허용되면 경로는 기록한다.

## 6. 현재 진행과 완료 기준

| 항목 | 현재 상태 |
| --- | --- |
| Pleos 프로젝트 | 생성 완료 — 사용자 확인 |
| 오디·국문 관광정보 API | 활용신청 완료 — 사용자 확인. 실제 호출 검증 전 |
| Pleos 개발 환경 | 설치 진행 중 — 사용자 확인 |
| 앱·서버 | 최소 프로젝트 및 SDK 실행 검증 전 |
| 모델 | 품질·지연 비교 전. 비용은 현재 선정 제약 아님 |
| 문서 | v0.8 데이터·상태·검수 계약 보완 |

준비된 근거→이야기→버튼 발화→답변→복귀를 먼저 연결한다. 다음으로 중단·중복·복구·수집을 검증한다. 문서 검증과 앱 실행 성공은 별도로 기록한다. P0 필수 테스트가 통과하고 SDK 미확인 항목이 해소되어야 데모 완료로 표시한다.
