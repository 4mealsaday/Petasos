# Petasos 디자인 기준 (v1, 2026-11-10)

이 문서가 UI 작업의 유일한 기준이다. 외부 디자인 시스템 파일을 그대로 넣지 않는다. 스타일 방향(평면·단색 파랑·Pretendard·절제된 버튼)은 모빌리티 앱 디자인 시스템을 참고했지만, 다른 브랜드의 로고·이름·고유 그래픽은 쓰지 않는다.

## 1. 원칙

- **평면**: 그라데이션·유리 질감·그림자 없음. 흰 표면 + 연회색 바탕 + 1px 구분선으로 층을 나눈다.
- **한 화면 한 주행동**: 화면마다 파랑 주 버튼은 최대 1개.
- **차량 크기**: 팔을 뻗어 누르는 화면이다. 터치 영역 최소 64dp, 본문 24sp.
- **줄이기**: 없어도 되는 버튼은 없앤다(새로고침·목록으로·중복 뒤로 가기 등). 자동으로 할 수 있는 건 자동으로.
- **주행 중**: 내비 위 표시는 두 줄 이하. 긴 문단을 흘리지 않는다.

## 2. 토큰

`res/values/colors_petasos.xml`, `dimens_petasos.xml`, `styles_petasos.xml`, `font/`로 분리한다. 기존 `colors_glass.xml`, `bg_glass_*`, 유리 관련 drawable·스타일은 삭제한다.

### 글꼴

Pretendard(SIL OFL)를 `res/font/`에 Regular·Medium·SemiBold·Bold 4개만 넣는다. 라이선스 파일을 함께 둔다.

| 스타일 | 크기/굵기/줄간격 | 용도 |
| --- | --- | --- |
| `Display` | 48sp / Bold / 60 | 홈 브랜드, 큰 숫자 |
| `Heading` | 36sp / Bold / 46 | 화면 제목 |
| `Title` | 28sp / SemiBold / 38 | 카드 제목, 버튼 큰 글씨 |
| `Body` | 24sp / Regular / 34 | 본문, 자막 |
| `Label` | 22sp / SemiBold / 30 | 탭, 칩, 작은 버튼 |
| `Caption` | 18sp / Medium / 26 | 보조 정보, 출처 |

위계는 색보다 크기·굵기로 만든다. 숫자는 Bold, 단위는 Regular(예: **17**곳).

### 간격·모서리

- 간격: 4dp 단위. 주로 8 / 12 / 16 / 24 / 32 / 48.
- 화면 안쪽 여백 32dp, 카드 안쪽 여백 32dp, 카드 사이 24dp.
- 모서리: 버튼 큰 것 20dp · 중간 16dp, 카드 24dp, 칩 완전 둥근(999), 내비 위 카드 28dp.

### 움직임

- 눌림: 크기 96% + 색 한 단계 진하게, 100ms.
- 화면 전환 애니메이션 없음(즉시 전환).
- 예외: 내비 위 원형 버튼의 "듣는 중" 테두리 맥동(1.2초 주기).

## 4. 로고

- 시안 A(날개 모자) 확정. 원본: `docs/design/petasos-logo.svg`.
- 앱 아이콘: 파랑 바탕 모서리 둥근 사각 + 흰 모자. 어댑티브 아이콘 전경/배경으로 분리.
- 내비 위 원형 버튼은 로고가 아니라 흰 마이크(`ic_mic`)를 쓴다(6.3). 말하기 기능이 바로 보이도록.
- 워드마크: "Petasos" Pretendard Bold, `text_strong`. 아래 부제 "지나는 길의 이야기" `Caption` `text_sub`.
- 모자 path는 VectorDrawable로 변환해 `ic_petasos_mark.xml` 하나로 공유한다.

## 5. 문구

- 존댓말 "-요". 버튼은 동사형, 마침표·느낌표 없음: 동행 시작, 동행 끝내기, 내비로 돌아가기, 다시 듣기.
- 사용자 소유 항목은 "내 …": 내 여행.
- 개발 용어 금지: "세션", "리비전", "정책", "proof" 등을 화면에 쓰지 않는다.

## 6. 화면

Pleos 화면에서 앱 영역은 오른쪽 약 1330×945px다(왼쪽은 차량 상태 패널). 이 영역 기준으로 배치하고, 실제 dp는 기기 DisplayMetrics로 확인한다.

### 6.1 첫 실행 (처음 한 번)

1. 권한 안내 1장: 위치(지나는 지역 확인), 마이크(말하기), 화면 위 표시(내비 위 버튼). 주 버튼 "계속하기".
2. 관심사 고르기: 칩 12개, 여러 개 선택. 주 버튼 "시작하기", 약한 버튼 "건너뛰기".

### 6.2 홈

```
┌ 상단바: [로고+Petasos]                              [⚙ 설정] ┐
│ ┌──────────── 동행 카드 (2/3) ────────────┐ ┌ 내 여행 (1/3) ┐ │
│ │ 꺼짐                                     │ │ 내 여행     › │ │
│ │ 출발하면 지나는 지역의 이야기를 들려드려요 │ │ ┌──────────┐ │ │
│ │  ① 동행 시작  ② 지역 이야기  ③ 버튼으로 질문 │ │ │ 작은 지도 │ │ │
│ │  위치 ✓   마이크 ✓   내비 위 표시 ✓      │ │ └──────────┘ │ │
│ │ [            동행 시작            ]      │ │ 14곳 · 이야기 4편│ │
│ │ 켜짐                                     │ │ 최근 11월 10일 │ │
│ │ 동행 중 · 서울 중구 / 지금: 문화역서울 284 │ └──────────────┘ │
│ │ [ 내비로 돌아가기 ]   [ 동행 끝내기 ]     │                  │
│ └──────────────────────────────────────────┘                  │
└──────────────────────────────────────────────────────────────┘
```

- **꺼짐 상태 동행 카드**
  - 제목 문장 아래에 **이용 3단계**를 아이콘 + 짧은 글로 가로 배치: ① 동행 시작(재생 아이콘) ② 지나는 지역 이야기(지도 아이콘) ③ 궁금하면 버튼으로 질문(마이크 아이콘). `Label`, `text_sub`, 아이콘 `primary`.
  - 그 아래 **준비 상태** 한 줄: 위치 · 마이크 · 내비 위 표시. 준비됐으면 `positive` 체크, 안 됐으면 `caution` 점 + "설정 필요"(누르면 해당 권한 요청/안내).
  - 맨 아래 주 버튼 "동행 시작".
- **켜짐 상태 동행 카드**: 현재 지역 `Heading`, 지금 재생 중인 이야기 제목 또는 "음악 · 곡명" `Body`, 아래 주 버튼 "내비로 돌아가기" + 약한 버튼 "동행 끝내기". 지역 확정 전에는 "출발하면 이야기를 들려드릴게요".
- **내 여행 카드**: 제목 + › , 가운데 **작은 지도**(자체 지도, 애니메이션 없음, 이야기 들은 지역 강조 + 다닌 길 선, 데모 경로 범위에 맞춤), 아래 숫자 요약. 기록이 없으면 지도 자리에 "아직 기록이 없어요". 카드 전체가 눌림 영역.
- 기존 홈의 고급 재생·소개·알림 영역은 삭제.

### 6.3 내비 위 표시 (overlay)

- **원형 버튼**: 96dp, 파랑 원 + 흰 마이크(`ic_mic`, 홈·자막 카드의 마이크와 같은 아이콘). 내비 지도 영역 오른쪽 가장자리에서 24dp 안쪽, 세로 가운데. 화면 밖으로 잘리지 않아야 한다.
  - 대기: 흰 테두리 4dp
  - 듣는 중: `primary_line` 테두리 맥동
  - 답변 준비 중: 마이크를 줄여 위로 올리고 그 아래 점 3개 순차 깜빡임
  - 서버 연결 실패 등: 테두리 `caution` 2초
- **자막 카드**: 내비 지도 오른쪽 아래. 내비 왼쪽 패널(검색창·경로 안내) 오른쪽(지도 왼쪽 끝에서 480dp), 음량·설정 버튼 왼쪽(화면 오른쪽 끝에서 128dp), "내 위치로"·도로명 표시 위(하단에서 108dp). 내비 대기·경로 안내 모두 같은 자리. `surface`, 모서리 28, 안쪽 여백 24.
  - 1줄(라벨): 상태 아이콘 + "서울 중구 · 문화역서울 284" `Label` `text_sub`
  - 2줄(본문): 지금 읽는 **문장 하나** `Title` `text_strong`, 최대 2줄 말줄임. 문장이 바뀔 때 교체.
  - 상태별 1줄 라벨: 이야기(책 아이콘), 음악(음표 + 곡명), 말하기(마이크 + "말씀해 주세요"/"듣고 있어요"), 답변(말풍선 + 인식된 질문)
  - 카드 안 버튼 없음(설정 아이콘 삭제).
- 주행 제한 상태: 2줄 본문을 숨기고 1줄 라벨만.
- Petasos 화면이 앞에 있을 때는 원형 버튼·자막 카드를 숨긴다(홈 카드가 같은 정보를 보여줌, 재생은 계속). 내비로 나가면 다시 보인다.

### 6.4 내 여행

```
┌ 상단바: [←]  내 여행                                [⚙] ┐
│ ┌──────── 지도 (3/5) ────────┐ ┌──── 패널 (2/5) ────────┐ │
│ │ 네이버 2D 지도 + 회색 덮개   │ │ [지역]  [여정]  (탭)    │ │
│ │ + 모든 여정의 다닌 길(선)    │ │ 지역: 지역 카드 목록    │ │
│ │ + 통과 지역 옅은 채움        │ │  (실루엣·이름·이야기 수)│ │
│ │ 선택한 여정/지역 강조         │ │ 여정: 날짜·구간·시간 목록│ │
│ └─────────────────────────────┘ └────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

- 지도: **네이버 지도 2D(일반 지도) 바탕 + 우리 표시층**. 위성 지도는 쓰지 않는다. 인터넷이 없거나 인증이 실패하면 자체 지도(`regions-display-v1.json`)로 대체한다.
  - 바탕 정돈: 2D 일반 지도. 건물·대중교통·지형 등 부가 레이어는 끄고, 지명 크기를 약간 줄이며, 지도 밝기를 낮춰 파란 선이 돋보이게 한다(밝기 조절 범위는 실제 화면으로 결정).
  - **모은 지역 = 이야기를 들은 지역**(지나가기만 한 지역은 아님). 이야기를 하나라도 끝까지 들은 시군구만 덮개가 걷히고, 나머지는 어두운 회색(`#141A24` 약 45%) 덮개. 경계선은 `#B4BBCB` 0.8dp. 다닌 길 선은 덮개와 무관하게 모두 표시.
  - 다닌 길: 저장된 위치 기록을 **원본 해상도로**(약 10m 간격 단순화만) 그린다. 바깥 빛 번짐 10dp `#0078FF` 35% + 본선 4dp `#0078FF`. 여러 여정이 겹칠수록 진해진다.
  - 화면 진입 애니메이션: 여정을 날짜순으로 약 3초에 걸쳐 그려 나가며 선 끝에 흰 점. 선이 지나는 순서대로, 그 여정에서 이야기를 들은 지역의 덮개가 걷힌다.
  - 확대/이동: 지도 기본 제스처. 여정·지역 선택 시 해당 범위로 맞춤. 지도 출처는 네이버 기본 표기 유지.
  - 후속(1차 제출 후): 다닌 도로를 도로망에 맞춰 붙이는 처리.
- 지역 탭: 카드 = 지역 실루엣 + 지역 이름 + "이야기 2편". "모은 지역"은 이야기를 들은 지역. 지나갔지만 이야기를 듣지 않은 지역과 안 간 지역은 회색 실루엣·흐린 글자로 뒤에 보여준다. 카드를 누르면 지도가 그 지역으로 이동·강조, 패널에 그 지역에서 들은 이야기 목록 + 이야기마다 "다시 듣기".
- 여정 탭: 날짜 · "서울 중구 → 대전 유성구" · 이동 시간. 누르면 지도에 그 여정만 강조, 패널 하단에 대화 요약.
- 삭제: 새로고침(화면 진입 시 자동), "목록으로", 작은 "‹ 홈", 범례 문장. 지도 출처는 지도 왼쪽 아래 `Caption` 한 줄.

### 6.5 설정

상단바 [←] 설정. 목록 행:

1. 위치 기록 (토글) — 설명 "지나온 길과 지역을 기기에만 저장해요"
2. 관심사 › (칩 선택 화면)
3. 데이터 출처 › (공공데이터·지도·음악 라이선스)
4. 앱 정보 › (버전)
5. (DEMO 빌드만) 청취 기록 초기화

기존 설정의 고급 재생·기록 다시 듣기·관심사 큰 격자 외 실험 기능은 삭제한다(다시 듣기는 6.4로 이동).
